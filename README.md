# Геоаналітика SPAR

Карта для оцінки локацій магазинів: зони пішої доступності, конкуренти, модель Хаффа, кандидати.

- **Сайт:** GitHub Pages, папка docs/.
- **Відкриті шари** (вулиці, будинки, магазини, зупинки) рахуються з OpenStreetMap щомісяця 1-го числа: .github/workflows/pages.yml → scripts/build_all.py (для кожного міста з scripts/cities.json: extract.py → bundle.py).
- **Міста:** список і межі — scripts/cities.json. Щоб додати місто, допишіть рядок із назвою та межами (bbox: захід, південь, схід, північ). Дані © OpenStreetMap contributors, ліцензія ODbL 1.0.
- **Дані мережі** (магазини, площі, чеки, кандидати) у репозиторії не зберігаються. Сторінка читає їх з Google Таблиці лише після входу через Google, і лише якщо цьому акаунту відкрито доступ до таблиці.

# Геоаналітика SPAR

Карта для оцінки локацій магазинів: зони пішої доступності, конкуренти, модель Хаффа, кандидати.

- **Сайт:** GitHub Pages, папка docs/.
- **Відкриті шари** (вулиці, будинки, магазини, зупинки) рахуються з OpenStreetMap щомісяця 1-го числа: .github/workflows/pages.yml → scripts/build_all.py (extract.py читає обидві області → bundle.py для кожного квадрата).
- **Покриття:** Закарпатська та Івано-Франківська області цілком, без вибору міста. docs/data/region.json — оглядовий шар (головні дороги, продуктові магазини, населені пункти, щільність забудови); docs/data/t/<x>_<y>.json — деталі квадрата 0,10° × 0,075° (≈7×8 км) із запасом ≈3 км, підвантажуються, коли карту наблизили. Дані © OpenStreetMap contributors, ліцензія ODbL 1.0.
- **Дані мережі** (магазини, площі, чеки, кандидати) у репозиторії не зберігаються. Сторінка читає їх з Google Таблиці лише після входу через Google, і лише якщо цьому акаунту відкрито доступ до таблиці.
